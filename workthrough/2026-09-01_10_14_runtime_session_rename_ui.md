# 런타임 세션 이름 변경 UI

## 개요
AI 런타임 설정의 세션 선택기에 이름 변경 기능을 추가했다. 네 런타임에서 동일한 편집 흐름을 제공하고 저장 결과를 즉시 다시 불러온다.

## 주요 변경사항
- 개발한 것: 세션 편집 아이콘, 이름 변경 다이얼로그, rename API 연결
- 개선한 것: 저장 중 상태와 실패 사유 표시, 빈 이름 방지
- 번역한 것: 영어·일본어·중국어 UI 문구

## 결과
- TypeScript 타입 검사 통과
- ESLint 통과
- Electron 프로덕션 빌드 통과
