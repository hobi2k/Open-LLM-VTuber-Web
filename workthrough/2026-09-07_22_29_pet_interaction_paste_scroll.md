# 펫모드 상호작용·이미지 붙여넣기·세션 스크롤 개선

## 개요
펫모드에서 캐릭터를 빠르게 드래그하면 이동이 끊기고 클릭이 데스크톱으로 빠지던 문제, 캐릭터 옆 데스크톱 클릭이 막히던 문제, 확대·축소가 잘 안 되던 문제를 수정했다. 이미지 붙여넣기와 세션 불러오기 스크롤도 함께 개선했다.

## 주요 변경사항
- 수정한 것: 모델 드래그 중에는 펫 창 전체를 상호작용 영역('live2d-drag')으로 잠가 빠른 드래그에도 클릭 통과가 발생하지 않도록 함
- 개선한 것: 모델 상호작용 영역 여백 96px→40px, 메인 프로세스 이탈 유예 750ms→250ms로 캐릭터 옆 데스크톱 클릭 회복
- 수정한 것: 스크롤 확대·축소의 이징 루프가 목표 도달 후에도 무한 실행되던 문제 종료 처리, 휠 스텝 0.03→0.08, 펫모드에서 휠 시 상호작용 유지
- 개발한 것: 입력창(창모드 footer·펫모드 도크)에 이미지 붙여넣기(onPaste) 지원으로 클립보드 이미지를 첨부로 추가
- 수정한 것: 세션 불러오기 시 위→아래로 애니메이션 스크롤되던 동작을 마지막 메시지로 즉시 이동(스트리밍 증가분만 부드럽게)
- 보강한 것: WebSocket 클라이언트 15초 하트비트로 유휴 연결 유지(백엔드 heartbeat-ack 처리)
