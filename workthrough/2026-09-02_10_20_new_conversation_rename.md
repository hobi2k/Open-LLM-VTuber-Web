# 새 대화 즉시 이름 변경

## 개요
AI 런타임 설정에서 새 대화를 선택한 직후에도 이름을 지정할 수 있게 수정했다. 기존 세션을 먼저 적용하거나 첫 메시지를 보낼 필요 없이 예약 제목이 화면에 즉시 표시된다.

## 주요 변경사항
- 새 대화 상태에서도 이름 변경 버튼 활성화
- 입력한 제목을 런타임별 `new_session_title` 설정으로 보관
- 예약 제목을 대화 필드와 도움말에 즉시 표시
- 프로젝트나 세션을 바꾸면 이전 예약 제목 초기화

## 결과
- 타입 검사 및 ESLint 통과
- 프런트 테스트 14개 통과
- Electron 프로덕션 빌드 성공
- 실제 UI에서 `새 대화 → 이름 변경` 흐름 확인
