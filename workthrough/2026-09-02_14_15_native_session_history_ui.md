# 네이티브 세션 이력 UI

## 개요
AI 런타임에서 기존 세션을 선택하면 원본 채팅 이력을 현재 타임라인에 자동으로 표시하도록 연결했다. 수동 세션 ID도 이력 버튼으로 불러올 수 있고 긴 세션은 표시 범위를 정확히 안내한다.

## 주요 변경사항
- 개발한 것: 세션 이력 자동·수동 불러오기와 로딩·성공·실패 상태
- 개선한 것: 전체 항목 수와 최근 1,000개 표시 범위를 구분한 안내
- 수정한 것: 설정 창 ASR 저장 콜백의 무한 상태 갱신 경고

## 결과
- ESLint 및 TypeScript 검사 통과
- 프런트 테스트 18개 통과
- 실제 Codex 장기 세션 복원, Markdown 표시, 콘솔 오류 0건 확인
