# 펫모드 코딩 타임라인 개선

## 개요
펫모드에서 최종 답변이 사라지고 입력 UI가 불편하던 문제를 수정했다. Codex 활동을 추론·명령·파일 변경·결과·최종 답변으로 구분해 일반 창과 펫모드 모두에서 읽을 수 있게 했다.

## 주요 변경사항
- 개발한 것: 펫모드 스크롤 타임라인, 멀티라인 입력, 구조화된 코딩 활동 카드
- 수정한 것: 빈 tool 이벤트가 최종 AI 답변을 대신 선택하던 문제와 raw JSON 표시
- 개선한 것: 펫 패널 우측 배치, 명령 중복 제거, 긴 결과 고정 높이 처리
- 수정한 것: 펫↔윈도우 전환 후 Live2D가 늦게 중앙으로 돌아오던 문제

## 결과
- TypeScript typecheck 및 Electron production build 통과
- 실제 Codex 파일 수정 흐름과 펫모드 `PET QA OK` 응답 확인
- 라이브 모드 복귀 0.7초 시점 Live2D 중앙 정렬 확인

## 다음 단계
