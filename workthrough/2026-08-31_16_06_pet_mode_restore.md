# 펫 모드 복구

## 개요
다중 모니터에서 펫 모드의 WebGL 캔버스가 지나치게 커져 Live2D 캐릭터가 사라지던 문제를 수정했다. 윈도우 모드의 전환 버튼과 Live 배지가 잘리지 않도록 사이드바 동선도 함께 정리했다.

## 주요 변경사항
- 펫 창을 앱이 있던 모니터의 작업 영역에 맞추도록 변경
- WebGL 최대 렌더버퍼 크기에 맞춰 캔버스 해상도를 제한
- 윈도우 화면에 명시적인 `펫 모드` 버튼 추가
- 펫 화면에 `윈도우 모드` 복귀 버튼 추가
- 사이드바 접기 핸들 영역 24px을 예약해 Live 배지 잘림 수정

## 결과
- 타입 검사 및 변경 파일 ESLint 통과
- Electron 빌드와 웹 빌드 통과
- arm64 패키징 및 코드 서명 검증 통과
- 실제 Live2D 캐릭터로 윈도우 -> 펫 -> 윈도우 왕복 확인
- 전체 저장소 ESLint는 생성된 `dist/web`과 기존 SDK 파일의 선행 오류로 실패

## 다음 단계
- 펫 캐릭터를 모니터 사이로 옮기는 기능이 필요하면 화면 단위 이동 명령으로 제공
- 생성 산출물과 SDK를 전체 ESLint 대상에서 제외하도록 설정 정리
