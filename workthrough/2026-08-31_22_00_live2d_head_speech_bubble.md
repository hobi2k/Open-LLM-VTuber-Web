# Live2D 머리 위 스트리밍 말풍선

## 개요
펫모드에서 추론과 작업 과정, 최종 응답을 Live2D 캐릭터 머리 위의 단일 말풍선으로 표시하도록 개선했다. 말풍선은 모델의 실제 렌더링 경계를 따라 이동하며 우측 패널은 입력과 상세 기록을 계속 담당한다.

## 주요 변경사항
- Cubism 렌더링 정점과 헤드 히트 영역을 화면 좌표로 투영하는 앵커 훅 추가
- 최신 추론, 파일 변경, 커맨드, 도구 결과, 최종 응답에 따라 같은 말풍선 내용과 아이콘을 실시간 교체
- 긴 스트림은 최신 부분이 보이도록 자동 스크롤하고 JSON 도구 입력은 읽기 쉬운 텍스트로 정리
- 반응형 너비, 화면 경계 보정, 상태별 색상과 캐릭터 방향 꼬리 적용

## 결과
- TypeScript typecheck, 대상 ESLint, Electron production build 통과
- 실제 Codex 파일 생성과 `cat` 실행에서 Thinking → Command/output → 최종 응답 전환 확인
- 캐릭터 머리 위 배치와 우측 상세 패널 동시 표시를 화면 검증
