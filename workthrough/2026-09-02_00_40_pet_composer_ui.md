# 펫모드 컴포저 UI 개선

## 개요
펫모드 입력창을 한 줄짜리 도구 막대에서 넓은 입력 영역과 하단 도구 행을 갖춘 전용 컴포저로 재설계했다. 캐릭터 아래 배치와 클릭 영역은 유지하면서 다중 행 입력과 이미지 첨부 상태의 가독성을 높였다.

## 주요 변경사항
- 입력 영역과 첨부 트레이, 도구 행을 하나의 일관된 패널로 통합
- 첨부, 윈도우 모드, 마이크와 중지, 전송 동작을 좌우 그룹으로 분리
- 실행 중에만 중지 버튼을 표시하고 빈 상태의 입력 폭을 확보
- 다중 행 입력을 최대 140px까지 자동 확장하고 작은 화면에서도 폭이 밀리지 않게 조정
- 포커스, 활성, 비활성 상태의 색상과 테두리, 그림자를 정돈
- 데스크톱 자동 백엔드가 사용자 site-packages를 읽지 않도록 격리해 패키지 기동 안정성 보강

## 결과
- 타입 검사 및 변경 파일 린트 통과
- Vitest 14개 테스트 통과
- Electron 프로덕션 빌드 성공
- 실제 펫모드에서 빈 입력, 다중 행, 이미지 첨부·제거, 윈도우 모드 복귀 확인
