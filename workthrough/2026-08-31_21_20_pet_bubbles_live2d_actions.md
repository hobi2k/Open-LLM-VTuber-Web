# 펫모드 말풍선과 코딩 Live2D 반응

## 개요
펫모드에서 긴 코딩 작업의 추론과 응답이 일부만 보이던 문제를 수정하고, TTS가 꺼진 코딩 모드에서도 Live2D 표정과 모션이 응답 상태에 맞춰 실행되도록 개선했다.

## 주요 변경사항
- 활성 코딩 턴의 사용자 입력, 추론, 명령, 파일 변경, 결과, 최종 응답을 스크롤 가능한 개별 버블로 표시
- 펫 패널의 실제 폭을 고정하고 다중행 입력, 한글 IME, Shift+Enter, 자동 높이와 빈 전송 방지를 정식 지원
- 입력 중 AI 상태가 `waiting`으로 잘못 바뀌던 동작 제거
- 무음 응답에서도 명시된 표정을 적용하고 성공, 오류, 경고, 일반 응답에 맞는 표정 fallback 추가
- 모델에 실제 존재하는 비-idle 모션 그룹과 모션 인덱스를 선택해 코딩 응답 반응 실행

## 검증
- TypeScript typecheck, 대상 ESLint, Electron production build 통과
- 실제 Codex 작업에서 다중행 한글 입력, 파일 변경, 커맨드 결과, 최종 응답의 펫모드 동시 표시 확인
- 최종 성공 응답 직후 `mao_pro`의 반응 모션 실행을 화면에서 확인

## 다음 단계
