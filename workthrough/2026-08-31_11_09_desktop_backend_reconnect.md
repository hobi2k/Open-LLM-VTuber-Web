# 데스크톱 백엔드 재연결 보강

## 개요
실제 앱 QA에서 Desktop의 로컬 백엔드가 늦게 준비되면 WebSocket 화면이 수동 재연결 상태에 머무는 문제를 보완했다. macOS의 Desktop 폴더 접근 설명도 앱 메타데이터에 추가했다.

## 주요 변경사항
- WebSocket 상태 구독을 초기 연결보다 먼저 등록
- 연결 종료 시 1.5초 간격 자동 재연결
- macOS Desktop 백엔드 접근 용도 설명 추가

## 결과
- 타입 검사 및 Electron 패키징으로 검증

## 다음 단계
