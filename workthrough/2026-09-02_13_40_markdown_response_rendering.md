# AI 응답 Markdown 렌더링

## 개요
채팅과 펫모드에서 AI의 Markdown 문법이 원문 기호로 노출되던 문제를 수정했다. 공용 렌더러로 일반 응답과 추론을 일관되게 표시하고, 스트리밍 중인 코드펜스도 안정적으로 유지한다.

## 주요 변경사항
- 개발한 것: CommonMark/GFM 기반 공용 Markdown 렌더러와 코드 복사 기능
- 수정한 것: 채팅·추론·펫모드 응답의 굵게, 목록, 링크, 인용문, 표, 코드펜스 표시
- 개선한 것: 미완성 스트리밍 코드펜스 보정, 좁은 펫모드 코드 스크롤, HTML 실행 차단
- 보존한 것: 사용자 원문 및 커맨드·파일 변경·권한 이벤트의 기존 개행과 전용 UI

## 결과
- 타입 검사 및 린트 통과
- 18개 테스트 통과
- Electron, 웹, macOS 앱 빌드 성공
- 680px 채팅과 360px 펫모드 시각 QA 및 콘솔 오류 0건 확인
