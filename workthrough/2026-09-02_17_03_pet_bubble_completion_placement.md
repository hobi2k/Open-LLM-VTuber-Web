# 펫모드 완료 상태와 말풍선 위치

## 개요
Claude 등 코딩 런타임의 응답이 끝난 뒤에도 펫모드가 계속 사고 중으로 남는 문제를 수정했다. 말풍선을 캐릭터 위, 왼쪽, 오른쪽 중 선택하고 앱 재실행 후에도 유지할 수 있게 했다.

## 주요 변경사항
- 개발한 것: Live2D 설정의 펫 말풍선 위치 선택과 공간 부족 시 자동 대체 배치
- 수정한 것: 완료 상태 해제가 오디오 큐에 막히던 문제와 오래된 AI 상태를 참조하던 문제
- 수정한 것: TTS 비활성화 시 빈 오디오로 전달되던 표시 텍스트를 오디오 큐에서 분리
- 개선한 것: 완료된 턴에서는 추론 이벤트보다 최종 응답을 우선 표시
- 보강한 것: 말풍선 선택 및 위치 계산 회귀 테스트 3개

## 결과
- TypeScript 타입 검사 통과
- ESLint 통과
- Vitest 21개 통과
- macOS arm64/x64 패키징 성공
- 설치 앱에서 오른쪽 배치, 최종 응답 표시, 재실행 후 설정 유지 확인
