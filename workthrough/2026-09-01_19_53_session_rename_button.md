# 세션 이름 변경 버튼 개선

## 개요
설정 화면의 세션 이름 변경 기능을 쉽게 찾을 수 있도록 연필 아이콘 전용 버튼을 아이콘과 텍스트가 함께 보이는 명령 버튼으로 개선했다.

## 주요 변경사항
- 세션 선택란 옆에 `이름 변경` 텍스트를 항상 표시
- 좁은 설정 패널에서도 버튼 글자가 잘리지 않도록 크기와 여백 고정

## 결과
- TypeScript 타입 검사 통과
- 프론트엔드 테스트 10개 통과
- Electron 프로덕션 빌드 성공

## 다음 단계
- 세션 목록 항목의 컨텍스트 메뉴에도 이름 변경 명령 제공 검토
