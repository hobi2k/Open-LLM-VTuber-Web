# 펫모드 상호작용 안정화

## 개요
펫모드에서 Live2D, 말풍선, 입력창이 클릭되지 않거나 모델이 사라지는 문제를 수정했다. 렌더러가 실제 요소 영역을 전달하고 Electron 메인 프로세스가 물리 커서 위치에 따라 데스크톱 클릭 통과를 제어하도록 정리했다.

## 주요 변경사항
- 개발한 것: Live2D, 입력창, 말풍선의 실제 화면 영역 IPC 전달
- 수정한 것: 펫 전환 중 포커스 해제와 반복적인 마우스 통과 전환 제거
- 개선한 것: 모델 96px, 입력창/말풍선 48px 여유와 750ms 이탈 유예 적용
- 안정화한 것: Cubism Core WASM이 실제 준비된 뒤 React와 Live2D 초기화 시작

## 결과
- 테스트 10개 통과
- TypeScript 및 ESLint 검사 통과
- Electron 프로덕션 빌드와 macOS x64/arm64 패키징 성공
- 개발 앱과 arm64 패키징 앱에서 Live2D 로드, 펫 전환, 모델 클릭, 입력, 말풍선, 창모드 복귀 확인
