# 펫모드 권한 UI 및 패키징

## 개요
코딩 에이전트의 추론, 도구 활동, 권한 요청과 슬래시 명령을 일반 창과 Live2D 펫모드 양쪽에 연결했다. 펫모드의 투명 영역은 클릭을 통과시키고 캐릭터, 말풍선, 입력창만 상호작용하도록 정리했다.

## 주요 변경사항
- 개발한 것: 런타임별 권한 카드, 질문 응답, 슬래시 명령/스킬 메뉴, 세션 이름 변경 UI
- 수정한 것: 펫모드 클릭 차단, 입력 중복, 창 전환 후 Live2D 위치와 포커스 문제
- 개선한 것: 추론/명령/diff/결과 말풍선, 다국어 설정 UI, Intel·Apple Silicon 패키지명

## 결과
- 프런트엔드 테스트 7개, 타입 검사, 빌드 통과
- 실제 펫모드, Codex 권한 거절, 네 런타임 응답 확인
- x64/arm64 DMG 생성 및 체크섬·코드 구조 검증 통과
