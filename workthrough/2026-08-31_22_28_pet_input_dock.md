# 펫모드 캐릭터 하단 입력 도크

## 개요
머리 위 스트리밍 말풍선과 중복되던 펫모드 우측 대화 패널을 제거했다. 펫모드에는 Live2D 캐릭터 발아래를 따라가는 컴팩트 입력 도크만 표시하도록 정리했다.

## 주요 변경사항
- 펫모드 타임라인과 메시지 카드 렌더링 제거
- Cubism 모델의 하단 렌더링 경계를 화면 좌표로 계산해 입력 도크 위치에 연결
- 라이브 모드, 마이크, 중단, 전송을 입력 도크 안의 아이콘으로 유지
- 다중행 입력 자동 높이, 화면 경계 보정, 버튼 오동작 방지 적용

## 결과
- TypeScript typecheck, 대상 ESLint, Electron production build 통과
- 실제 펫모드에서 우측 패널 제거와 캐릭터 하단 입력 도크 배치 확인
- 모델 위치 변경 시 입력 도크 추적과 머리 위 말풍선 단독 표시 확인
