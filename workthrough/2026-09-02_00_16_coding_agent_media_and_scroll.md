# 코딩 에이전트 첨부와 탐색 UX 보강

## 개요
창 모드와 펫 모드에서 이미지 파일을 첨부해 AI 런타임으로 보낼 수 있게 했다. 긴 활동 출력과 세션 목록을 끝까지 탐색할 수 있도록 스크롤 동작을 보강하고, 파일 수정 활동에는 확장자 기반 언어 배지를 표시한다.

## 주요 변경사항
- 개발한 것: PNG/JPEG/WebP/GIF 다중 첨부, 미리보기, 삭제, 6장/장당 12MB 검증
- 수정한 것: 펫 말풍선 출력 길이 제한 제거, 사용자 스크롤 위치 보존, 세션 드롭다운 내부 스크롤
- 개선한 것: 파일 수정 활동에 TSX, Python, Rust 등 언어 배지 표시
- 검증한 것: 세션 3,543개 목록에서 실제 휠 스크롤과 첨부 UI의 창/펫 모드 전환

## 결과
- TypeScript 타입 검사 및 ESLint 통과
- Vitest 14개 통과
- Electron 프로덕션 빌드 성공
